# Images

The section names in the table are the Czech headings used on the live site.

| File                  | Where it shows up                                          |
|-----------------------|------------------------------------------------------------|
| `spidey-band.webp`    | icons in the bands and next to headings, fallback photo in "Za maskou" (Behind the mask) |
| `spidey-hang.webp`    | hanging Spider-Man (Dovednosti / Skills, Kontakt / Contact) |
| `spidey-stand.webp`   | standing Spider-Man (Projekty / Projects) and, for now, the intro |
| `web.webp`            | the webs                                                   |
| `projects/*.webp`     | project thumbnails                                         |

## Your own photos

| File             | What it does                                                             |
|------------------|--------------------------------------------------------------------------|
| `hero-mask.jpg`  | Intro — you in the suit WITH the mask (top layer). Once it is here, it replaces the standing Spider-Man. |
| `hero-face.jpg`  | Intro — the same photo WITHOUT the mask (bottom layer). The cursor uncovers it, so it has to line up pixel for pixel with `hero-mask.jpg`. |
| `me.jpg`         | Your photo in the round frame in "Za maskou" (square, face in the middle). |
